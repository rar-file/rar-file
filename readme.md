#### What I'm building

**Right now**

- **[claude-rpc](https://github.com/rar-file/claude-rpc)**: Discord Rich Presence for Claude Code. Live model, project, tokens and lifetime stats on your Discord profile, driven by the hooks Claude Code already fires. `npx claude-rpc@latest setup` · [claude-rpc.com](https://claude-rpc.com)
- **[cambium](https://github.com/rar-file/cambium)**: Trees grown year by year from a seed. A self-organising silver birch growth model for games and science, checked against real forests.

**Tools**

- **[surf](https://github.com/rar-file/surf)**: Self-hosted AI chat with web UI + terminal CLI. Any model (Ollama, Anthropic, OpenAI, OpenRouter), web search, browser agent, persistent memory.
- **[phoney](https://github.com/rar-file/phoney)**: Zero-dependency Python library for locale-aware fake personal data. 43 locales, for tests, demos and anonymized fixtures.
- **[burner](https://github.com/rar-file/burner)**: One-click fake signup identities, deterministic per site. Chrome extension built on phoney, 100% local.
- **[STILE](https://github.com/rar-file/STILE)**: The captcha that lets AI agents in. Invisible to humans, trivial for any LLM. Zero-dependency Node middleware for Express, Fastify, Hono, Next.js and Cloudflare Workers.
- **[redactly](https://github.com/rar-file/redactly)**: Drop in a PDF and the sensitive text is removed from the file, not hidden under a black box.

**Side projects**

- **[aspect](https://github.com/rar-file/aspect)**: The browser window is the controller. A minimalist physics puzzle where reshaping the window tilts gravity. [Play it](https://aspect-lovat.vercel.app)
- **[autonomy](https://github.com/rar-file/autonomy)**: OpenClaw skill that picks actions from context instead of a fixed plan.
- **Subvocalization**: silent sEMG → speech. A small side project for now, kept private.
